FR Rapor Bridge - Musteri Kurulumu
==================================

1) FrRaporBridge-Kurulum.zip dosyasini POS bilgisayara kopyalayin
2) Zip'i acin
3) KUR.bat dosyasina CIFT TIKLAYIN
4) UAC penceresinde Evet deyin
5) Postgres sifresini IKI KEZ girin (begum)
   Host/port icin Enter = varsayilan (127.0.0.1 / 5432 / fastrest)
   Kurulum sifreyi kaydeder ve Postgres baglantisini test eder.
   Test basarisizsa servis KURULMAZ (sifre kaybolmaz).
6) "Sifre kaydedildi (N karakter)" ve "Postgres OK" satirlarini gorun
7) Ekranda XXX-XXX esleme kodu cikar
8) FR Rapor > Admin > Subeler > Yeni Sube > "Kod ile bagla"
   Kodu bir kez yazin. Baglanti KALICIDIR.

ONEMLI - Sifre nerede?
- Gercek sifre: C:\ProgramData\FrRaporBridge\config.json  (pgPassword)
- FR Rapor Admin ekranindaki "DB sifre" alani agent subelerde BOS kalir = normal
- Bos gorunuyorsa Admin formuna bakmayin; config.json'da Length > 0 olmali

Gereksinimler:
- Windows 10/11 (64-bit)
- FastRest Postgres ayni PC'de (veya erisilebilir)
- Internet (FR Rapor bulutuna cikis)

Sorun giderme:
- Log: C:\ProgramData\FrRaporBridge\bridge.log
- Kod: C:\ProgramData\FrRaporBridge\PAIR-CODE.txt
- Servis: services.msc > FR Rapor Bridge
- Sifre degistir: set-password.ps1 (Yonetici)
- Kaldir: uninstall.ps1 (Yonetici)

Not: Kod 45 dk sadece ILK esleme icindir. Esledikten sonra tekrar kod gerekmez.
